# Stormwater Dynamic Solutions website

Static website for Stormwater Dynamic Solutions and the SDS BMP Tracker, served with GitHub Pages.

Pages: `index.html` (home), `platform.html` (SDS BMP Tracker), `solutions.html`, `services.html`, `contact.html`.
Shared styles are in `css/site.css`; the contact form script is in `js/form.js`; images are in `images/`.

The contact form posts through FormSubmit to the company email address set in `contact.html` and `js/form.js`.
